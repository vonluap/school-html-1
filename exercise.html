Web design

Hvad er web design?

Når man arbejder med web design, indgår der mange forskellige fagligheder og discipliner. Det handler blandt andet om informations design, interaktions design og grafisk design.

Informations design

Når vi skal lave et website, skal man vide, hvad man vil sige på sitet – med andre ord hvad skal indholdet være. Man skal også forholde sig til, hvad der skal stå hvor.

Et website består af flere sider, der organiserer indholdet på en hensigtsmæssig måde, så det bliver tydeligt og let for brugeren at finde det ønskede indhold.

Interaktions design

Interaktions design handler om, at brugerne kan finde det, de leder efter. Det handler om at gøre sit site så brugbart og nyttigt som muligt.

Jakob Nielsen har fremsat 5 kvalitetskomponenter:

  • Learnability
  • Efficiency
  • Memorability
  • Errors
  • Satisfaction

Grafisk design

Grafisk design handler om det visuelle udseende af siderne. Et godt grafisk design skal passe til sitets budskab og give en god oplevelse.

Gestaltregler

  1. Nærhed – Figurer der er tæt på hinanden ses som en gruppe.
  2. Lighed – Ens figurer opfattes som en gruppe.
  3. Lukkethed – Delelementer sættes sammen til en helhed.
  4. Kontinuitet og symmetri – Symmetriske figurer ses som en gruppe.
  5. Prægnans – Hjernen leder efter mønstre og sammenhæng.
  6. Erfaring – Dækker blandt andet over brugen af ikoner.
  7. Forbundethed – Figurer med en streg imellem opfattes som sammenhørende.

Værktøjer og teknologier

HTML og CSS er grundlæggende teknologier til produktion af hjemmesider. De bliver administreret af World Wide Web Consortium (W3C).

HTML

HTML står for Hyper Text Markup Language. Det bruges til at mærke de forskellige dele af hjemmesiden, så browseren ved, hvilket element der er tale om, for eksempel en overskrift, en underoverskrift eller et link.

CSS

CSS står for Cascading Style Sheet. Med CSS kan man ændre hjemmesidens udseende.

Og meget mere...

Der findes mange flere teknologier, der kan bruges til at lave websites. HTML og CSS hører dog til det mest grundlæggende.
